# V8 heap profile

The V8 heap profile is a JSON format produced by
[V8's sampling heap profiler](https://v8.dev/docs/profile). It is generated by
Node.js and Chrome DevTools.

Unlike heap snapshots, which capture all live objects at a point in time, heap
profiles sample allocations. This makes them useful for finding allocation
hotspots rather than diagnosing what is currently live in memory.

It supports a single byte metric per profile and a single profile per file.

Files use the `.heapprofile` extension.
